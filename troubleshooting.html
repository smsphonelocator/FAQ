🛠️ Troubleshooting – SMS Phone Locator
Google Pixel & Xiaomi (RCS / Chat / SMS blocked)

Some devices — especially Google Pixel and Xiaomi — use advanced SMS features: Chat / RCS messaging, spam filtering, and background restrictions.
These may prevent SMS Phone Locator from sending or receiving command messages.

Important: SMS Phone Locator works only with standard SMS.
If Chat/RCS is active, commands like GPS <secret code> or RING <secret code> may not work.

1. General checks

Before changing advanced settings, verify:

  1. The phone you're trying to locate is powered on and has network signal.
  2. The SIM card can send and receive normal SMS messages.
  3. SMS Phone Locator is installed and configured, including:
  • A valid secret code has been set.
  • The following permissions are enabled:
    • Location
    • SMS
    • Notifications
    • Camera (for flash)
  • Android’s setting "Remove permissions if app is unused" is disabled.
If commands aren’t recognized or no response is received, RCS or spam filtering is likely the cause.

2. Google Pixel — Disable Chat/RCS

2.1 Disable Chat/RCS

  1. Open the Messages app.
  2. Tap ⋮ → Settings.
  3. Select Chat features.
  4. Turn off Enable chat features.
  5. If available, enable: “Send as SMS when Chat is unavailable.”
Messages will now be sent as standard SMS, allowing commands to work.

2.2 Check spam protection and blocked list

  • Open Messages → ⋮ → Spam & blocked.
  • If SMS Phone Locator messages appear there, mark them as Not spam.

3. Xiaomi — Permissions, battery & filters

Xiaomi devices use aggressive power management that may block SMS in background.

3.1 Allow required permissions

  1. Settings → Apps → Manage apps → SMS Phone Locator → Permissions
  2. Enable:
    • SMS
    • Location (Always)
    • Camera
    • Notifications

3.2 Allow Auto-start

Security → Permissions → Auto-start → Enable for SMS Phone Locator

3.3 Battery: No restrictions

Battery → App battery saver → SMS Phone Locator → No restrictions

If battery optimization stays active, SMS commands may never trigger.

4. Test procedure

4.1 Test GPS command

GPS: yourcode
You should receive:
  • A confirmation reply
  • A Google Maps link with location + battery

4.2 Test RING command

RING: yourcode
The phone should ring and flash.

🛠️ Dépannage – SMS Phone Locator
Google Pixel & Xiaomi (RCS / Chat / SMS bloqués)

Certains téléphones — notamment Google Pixel et Xiaomi — utilisent des fonctions avancées comme Chat / RCS, filtres anti-spam et restrictions d’arrière-plan.
Ces options peuvent empêcher SMS Phone Locator de recevoir ou d’envoyer les commandes SMS.

Important : SMS Phone Locator fonctionne uniquement avec des SMS classiques.
Si le mode Chat/RCS est activé, les commandes GPS <code> ou RING <code> peuvent ne pas fonctionner.

Sommaire

  • 1. Vérifications générales
  • 2. Google Pixel : désactiver RCS/Chat
  • 3. Xiaomi : permissions, batterie & anti-spam
  • 4. Tests recommandés

1. Vérifications générales

  1. Le téléphone cible est allumé avec du réseau.
  2. La carte SIM peut envoyer/recevoir des SMS classiques.
  3. L’application SMS Phone Locator est configurée :
  • Un code secret est défini.
  • Autorisations activées :
    • Localisation
    • SMS
    • Notifications
    • Caméra (flash)
  • L’option Android "Supprimer les autorisations si l’app n’est pas utilisée" est désactivée.
Si les commandes ne fonctionnent pas, RCS ou un filtre anti-spam est probablement responsable.

2. Google Pixel — Désactivation de RCS

2.1 Désactiver RCS

  1. Ouvrir Messages.
  2. Menu ⋮ → Paramètres.
  3. Fonctionnalités de chat.
  4. Désactiver Activer les fonctionnalités de chat.
  5. Activer (si présent) : “Envoyer par SMS si le chat n’est pas disponible.”
Tous les messages seront envoyés en SMS classique — nécessaire au fonctionnement.

2.2 Vérifier spam & numéros bloqués

  • Messages → ⋮ → Spam & conversations bloquées.
  • Si les réponses de l’app sont là → Non spam.

3. Xiaomi — Permissions & batterie

3.1 Autorisations

Paramètres → Applications → Gérer → SMS Phone Locator → Permissions

  • SMS
  • Localisation (Toujours)
  • Caméra
  • Notifications

3.2 Autoriser démarrage automatique

Sécurité → Permissions → Démarrage automatique → activer l'application

3.3 Batterie : aucune restriction

Batterie → Optimisation → SMS Phone Locator → Aucune restriction

Si optimisé, Xiaomi peut empêcher l’application de fonctionner en arrière-plan.

4. Tests conseillés

4.1 Commande GPS

GPS: toncode
Résultat attendu :
  • Message de confirmation
  • Carte Google Maps avec batterie

4.2 Commande RING

RING: toncode
Le téléphone doit sonner et flasher.
